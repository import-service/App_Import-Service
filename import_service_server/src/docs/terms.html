Приложение предназначено для клиентов Компании: создание и сопровождение заявок на таможенное оформление автомобилей, загрузка документов, просмотр статусов, обмен сообщениями, получение уведомлений и связанные функции. Отдельный режим предусмотрен для менеджеров СВХ (по учётным данным, выданным Компанией).
