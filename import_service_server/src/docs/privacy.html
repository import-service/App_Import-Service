1. Общие положения

Настоящая Политика определяет порядок обработки персональных данных пользователей мобильного приложения «Импорт Сервис» (далее — Приложение), предназначенного для оформления и сопровождения заявок на таможенное оформление автомобилей и связанных услуг.

Обработка осуществляется в соответствии с Федеральным законом № 152-ФЗ «О персональных данных» и иными применимыми нормами РФ.

2. Какие данные мы обрабатываем

В зависимости от использования Приложения могут обрабатываться:

  • данные учётной записи: логин (e-mail), ФИО / наименование организации, ИНН, телефон;
  • данные заявок: сведения об автомобиле (марка, модель, VIN), комментарии, статусы;
  • файлы и изображения, загружаемые пользователем (паспорт, документы, фото авто и др.);
  • переписка в чатах Приложения (с менеджером и/или менеджером СВХ);
  • технические данные: токены авторизации, идентификаторы устройств для push-уведомлений, сведения о версии приложения, журналы ошибок (без избыточного сбора);
  • оценки и отзывы по заявкам, если пользователь их оставляет.

3. Цели обработки

  • предоставление функций Приложения (создание и ведение заявок, обмен документами, чат, уведомления);
  • идентификация пользователя и обеспечение безопасности доступа;
  • исполнение договорных и связанных с услугами обязательств Оператора;
  • улучшение стабильности Приложения (диагностика сбоев);
  • исполнение требований законодательства РФ.

4. Правовые основания

Обработка выполняется на основании согласия пользователя (при регистрации / использовании Приложения), договора (оказание услуг), а также в случаях, предусмотренных законом.

5. Передача данных третьим лицам

Данные могут передаваться внутренним информационным системам Оператора (включая учётные системы) в объёме, необходимом для исполнения заявки. Для работы Приложения могут использоваться инфраструктура хостинга, сервисы доставки push-уведомлений (например, Firebase Cloud Messaging / сервисы магазинов приложений) и иные подрядчики, обязанные обеспечивать конфиденциальность.

Мы не продаём персональные данные третьим лицам в маркетинговых целях.

6. Хранение и защита

Данные хранятся на защищённых серверах с использованием HTTPS и разграничения доступа. Срок хранения — в течение периода использования Приложения и сроков, необходимых для исполнения обязательств и требований законодательства, после чего данные удаляются или обезличиваются в установленном порядке.

7. Права пользователя

Вы вправе запросить доступ, уточнение, блокирование или удаление своих персональных данных (с учётом ограничений, установленных законом), а также отозвать согласие на обработку, направив обращение на info@import-service.su.

8. Данные детей

Приложение не предназначено для лиц младше 18 лет. Мы сознательно не собираем данные детей.
