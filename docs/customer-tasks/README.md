# Задачи и правки от заказчика

Живой трекер: пока задача **не закрыта**, здесь лежит актуальный статус, цитата, план и проверка.

## Правила для агента

1. Новое сообщение/скрины заказчика → **сразу** обновить или создать файл в этой папке (не ждать «повтори»).
2. В каждом файле задачи: цитата → понимание → что уже проверено → план → «Как проверить» → статус.
3. Закрывать задачу только после проверки (или явной отмены заказчиком).
4. Не путать с HTML `/docs` (для 1С/людей) и с `.mdc` (канон агента). Это **оперативный** трекер переписки.
