## Что изменилось (накопительно, с 2026-10-08)

- Чат: открытие вложений — исправлена склейка URL (`/api/api/…` → нормальный path).
- Чат: имена файлов без подчёркивания; длинные имена сокращаются с точками в середине (порог **25** символов, расширение сохраняется).
- Сервер (уже на API): при скачивании файла отдаётся `Content-Disposition` с именем и расширением (удобнее для 1С «Сохранить как»).
- Установка APK с сервера: показывается системное окно подтверждения (раньше Intent отбрасывался).
- Оценка на карточке «Доставлено» — только после подстатуса «Выдано клиенту».
- Список заявок: красные алармы по чеку/подписи без обязательного открытия деталки (в list есть files).
- Баннер «Подпишите документы» не возвращается после загрузки всех подписей.
- Подстатус 1С в списке — зелёным текстом под чипом статуса.
- У клиента всегда видны секции «Фото/Видео машины» (загружает менеджер СВХ).
- После загрузки подписанного документа секция «На подпись» больше не сворачивается.
- Быстрый вход QA: клиент `admin@gmail.com` в списке недавних входов.
- Chat WSS: стабильный порт; декларант/СВХ снова подключаются к комнате заявки.
